# COROS Analysis Skill

[English](README.md) | [简体中文](README.zh-CN.md)

通过官方 COROS MCP，把训练、恢复、睡眠和日常活动放在一起分析的开源 AI 技能。

**有据可查的观察，结合个人背景的解释，可执行的下一步。**

这是供兼容 AI 助手使用的技能指令，不是独立应用，也没有自行发明生理预测模型。本项目由社区独立维护，与 COROS 无隶属或官方背书关系。

## 能做什么

- **每周复盘：** 对比训练、睡眠、恢复与日常活动，找出相对个人历史最有意义的变化。
- **今日状态：** 结合现有恢复信号、当天课程和你的时间安排，讨论训练选择。
- **长期趋势：** 观察数周或数月的训练连续性，以及条件可比的运动表现。
- **单次深挖：** 查看分圈、地形、强度，以及运动前后的恢复。
- **专题探索：** 讨论短睡、高负荷等现象之间的关系，明确相关性不等于因果。

跑步、骑行、游泳、徒步、力量等按各自特点分析，不用跑量代表所有运动。

## 使用条件

1. 支持技能和 MCP 工具的 AI 助手，例如 Codex。
2. 已通过官方 COROS 插件或连接器授权你的账户。
3. 已同步的设备记录。不同设备、佩戴情况和运动类型可提供的数据不同。

技能本身不会代你登录高驰，也不绑定某个安装专属的工具前缀。

官方指南：[COROS MCP 仓库](https://github.com/coroslab/COROS-MCP) · [官方更新说明](https://www.coros.com/stories/coros-metrics/c/mcp-testing)

## 在 Codex 中安装

克隆仓库，将 `skills/coros-analysis` 文件夹放到个人技能目录：

```bash
git clone https://github.com/Must-2001/coros-analysis-skill.git
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R coros-analysis-skill/skills/coros-analysis \
  "${CODEX_HOME:-$HOME/.codex}/skills/"
```

如果已经有同名技能，先检查或备份再复制。如果助手尚未刷新技能列表，可开启新对话。其他助手的技能位置可能不同，使用同一份 `SKILL.md` 即可。

## 使用示例

> 用 $coros-analysis 综合复盘我最近一个完整周的训练、睡眠和日常活动。
> 跟我自己的历史比较，指出最重要的变化、证据和下周的调整建议。

也可以问：

- “最近一次长徒步之后，我的恢复过程怎么样？”
- “这两次跑步有什么差别？考虑地形和强度。”
- “今天只有 40 分钟，昨晚没睡好，看看原计划怎么安排更合适。”
- “过去八周，我的训练连续性和恢复有什么变化？”

默认按你的语言作答，无需中英文各问一次。

## 分析原则

周报默认分析最近七个完整的本地自然日，以此前 28 天作为背景。先检查数据覆盖率，再针对重要变化读取详情。接口历史范围不足时会明确说明。

结果区分**事实、可能解释、行动建议**；COROS 官方评估和 AI 的判断分别标明。缺失不等于零，今天未结束的数据不直接与完整日比较，不虚构综合恢复分、疾病诊断、伤病预测或保证比赛成绩。

详见[分析方法](skills/coros-analysis/references/analysis-methods.md)、[工具路由](skills/coros-analysis/references/coros-tools.md)和[中英文虚构示例](examples/weekly-review.md)。

## 隐私与控制

默认只读。连接数据不代表允许修改课程和训练计划；只有你明确提出写入请求，才进入相应修改流程。仓库不包含真实运动记录、凭据、轨迹或设备标识。分析默认留在对话里，只有你要求导出时才保存。请勿向公开仓库提交个人数据。

本技能不作医疗诊断，恢复百分比也不能作为医学许可。有令人担忧的症状或医疗问题时，应寻求适当的专业评估。
